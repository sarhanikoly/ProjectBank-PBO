# Project PBO - Polymorphism

## Deskripsi
Program Java untuk simulasi transaksi bank menggunakan konsep:
- Method Overloading
- Method Overriding
- Polymorphism

## Struktur File
- Main.java
- Bank.java
- BankBNI.java
- BankBCA.java

## Cara Menjalankan
javac *.java
java Main


## Output
Menampilkan simulasi transfer uang dan suku bunga tiap bank.
